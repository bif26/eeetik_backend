📦 STEP 1: PUSH IMAGES TO DOCKER HUB (5 minutes)
────────────────────────────────────────────────────────────────────────────

Run this command:

    ./push-to-dockerhub.sh

What it does:
  • Logs you into Docker Hub (you'll enter your password)
  • Pushes both images to Docker Hub
  • Verifies success

After this, your images will be live at:
  • https://hub.docker.com/r/bif12/eeetik-backend-api
  • https://hub.docker.com/r/bif12/eeetik-backend-worker


🔧 STEP 2: FIX GITHUB ACTIONS (Optional, 10 minutes)
────────────────────────────────────────────────────────────────────────────

This makes future deployments automatic.

1. Create Docker Hub access token:
   https://hub.docker.com/settings/security
   → Click "New Access Token"
   → Name: "GitHub Actions - eeetik_backend"
   → Permissions: Read, Write, Delete
   → Copy the token

2. Add token to GitHub:
   https://github.com/Bif12/eeetik_backend/settings/secrets/actions
   → Create/Update "DOCKER_HUB_TOKEN"
   → Paste the token
   → Save

3. Test the workflow:
   git commit --allow-empty -m "Test GitHub Actions"
   git push origin main


🚀 STEP 3: DEPLOY TO KUBERNETES (15 minutes)
────────────────────────────────────────────────────────────────────────────

On your Kubernetes cluster, run:

    ./infra/k8s/deploy.sh

This deploys:
  • API service
  • Worker service
  • MongoDB (with persistent storage)
  • Redis (with persistent storage)
  • MinIO (with persistent storage)
